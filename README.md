# Dotfiles

Personal configuration files for Hyprland (Lua config) + Noctalia desktop on CachyOS.

## Layout

| Path | Deploy target | Notes |
|------|--------------|-------|
| `hypr/` | `~/.config/hypr/` | Hyprland config (hyprland.lua + modules/, hypridle.conf) |
| `noctalia/config.toml` | `~/.config/noctalia/config.toml` | Noctalia main config (idle, lockscreen) |
| `noctalia/settings.toml` | `~/.local/state/noctalia/settings.toml` | Noctalia overrides from the Settings UI (gitignored, not synced) |
| `noctalia/lockscreen-bg.png` | `~/.config/noctalia/lockscreen-bg.png` | Lock screen wallpaper |
| `fonts/` | `~/.local/share/fonts/` | Fonts (e.g. "The Last Shuriken" lock clock font) |
| `fuzzel/` | `~/.config/fuzzel/` | Launcher theme (generated, gitignored) |
| `yazi/` | `~/.config/yazi/` | File manager theme (generated, gitignored) |
| `gtk-3.0/`, `gtk-4.0/` | `~/.config/gtk-3.0/`, `~/.config/gtk-4.0/` | GTK themes (generated, gitignored) |
| `systemd/user/openrgb.service` | `~/.config/systemd/user/` | Starts OpenRGB at login (applies Zones profile) |
| `systemd/user/openrgb-quit.service` | `~/.config/systemd/user/` | Quits OpenRGB gracefully before shutdown (applies its exit profile) |
| `fastfetch/`, `kitty/`, `.zshrc`, `.p10k.zsh`, `.gitconfig` | various | Shell/terminal config |

## Notes

- Hyprland uses the Lua config (`hyprland.lua` requires `modules/*.lua` and
  `require("noctalia").apply_theme()`).
- `hyprtoolkit.conf`, `hypr/noctalia.lua`, `fuzzel/`, `yazi/`, `gtk-3.0/`,
  `gtk-4.0/` and `noctalia/settings.toml` are auto-generated by Noctalia's
  theme/applying logic — they are snapshots that may be rewritten. They are
  not tracked by git (see `.gitignore`); each machine keeps its own
  regenerated copy and the repo does not carry them.
- `noctalia/settings.toml` lives under the *state* dir at runtime and is
  regenerated by the Noctalia Settings UI (gitignored).
- **Host detection**: `hypr/modules/host.lua` picks a monitor/workspace preset
  at Hyprland load time. It checks `~/.config/machine` first, then `/etc/hostname`
  (`William-Laptop` → `laptop`); anything else falls back to the `pc` preset.
  To pin a machine to another preset: `echo pc > ~/.config/machine` (or `laptop`).
- Monitor names (DP-3, DP-2, HDMI-A-1, eDP-1) and absolute paths are
  machine-specific and resolved through the host preset.
- Idle behavior is handled by Noctalia (`config.toml`): dim at 5 min, lock at
  10 min, lock-and-suspend at 15 min.
