# Dotfiles

Personal configuration files for Hyprland (Lua config) + Noctalia desktop on CachyOS.

## Layout

| Path | Deploy target | Notes |
|------|--------------|-------|
| `hypr/` | `~/.config/hypr/` | Hyprland config (hyprland.lua + modules/, hypridle.conf) |
| `noctalia/config.toml` | `~/.config/noctalia/config.toml` | Noctalia main config (idle, lockscreen) |
| `noctalia/settings.toml` | `~/.local/state/noctalia/settings.toml` | Noctalia overrides from the Settings UI |
| `noctalia/lockscreen-bg.png` | `~/.config/noctalia/lockscreen-bg.png` | Lock screen wallpaper |
| `fonts/` | `~/.local/share/fonts/` | Fonts (e.g. "The Last Shuriken" lock clock font) |
| `fuzzel/` | `~/.config/fuzzel/` | Launcher theme (generated) |
| `yazi/` | `~/.config/yazi/` | File manager theme (generated) |
| `gtk-3.0/`, `gtk-4.0/` | `~/.config/gtk-3.0/`, `~/.config/gtk-4.0/` | GTK themes (generated) |
| `fastfetch/`, `kitty/`, `.zshrc`, `.p10k.zsh`, `.gitconfig` | various | Shell/terminal config |

## Notes

- Hyprland uses the Lua config (`hyprland.lua` requires `modules/*.lua` and
  `require("noctalia").apply_theme()`).
- `hyprtoolkit.conf`, `hypr/noctalia.lua`, `fuzzel/`, `yazi/`, `gtk-3.0/`,
  `gtk-4.0/` and `noctalia/settings.toml` are auto-generated by Noctalia's
  theme/applying logic — they are snapshots that may be rewritten.
- `noctalia/settings.toml` lives under the *state* dir at runtime and is
  regenerated by the Noctalia Settings UI.
- Monitor names (DP-3, DP-2, HDMI-A-1) and absolute paths are machine-specific
  and kept as-is.
- Idle behavior is handled by Noctalia (`config.toml`): dim at 5 min, lock at
  10 min, lock-and-suspend at 15 min.
